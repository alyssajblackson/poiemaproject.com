HOW TO APPLY TO YOUR EXISTING WEBSITE
1. Download and UNZIP this folder on your computer.
2. Open https://github.com/alyssajblackson/poiemaproject.com
3. Choose Add file > Upload files.
4. Drag the HTML files and poiema-editorial.css into the ROOT of the repository.
   Keep the exact filenames. Upload as files, NOT as a single ZIP.
5. Commit changes. Replace existing files when GitHub prompts you.
6. Do NOT delete any existing files. Your current photo assets, PDFs, favicon,
   domain configuration (CNAME), and special campaign pages must remain.
7. Refresh https://poiemaproject.com/ after GitHub Pages publishes.
   If old CSS appears, hard-refresh the browser.
