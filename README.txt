HOW TO PUBLISH TO GITHUB PAGES
1. Open your website repository in GitHub.
2. Upload the .html files in this folder into the SAME directory as the current index.html.
3. Choose to overwrite files with matching names, and add menstrual-classes.html.
4. Commit the changes to your publishing branch.
5. Open your homepage and click Classes in the desktop and mobile menus.
6. Click Ask About Hosting a Class and confirm the contact form selects "Menstrual class or workshop".

Your existing image assets, PDF files, and any pages not included here should remain in the repo.
